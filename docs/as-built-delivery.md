# 竣工图处理与交付

1. 按当前有效目录、图签和台账核对源图。用项目、单体、专业、图号、页序和布局定位图页。编号重复时比较适用范围、内容及版本。记录本轮需要更新的正式文件或送审副本。
2. 按 [换框流程](workflow.md) 提取旧图签、确定页界、导入模板和迁移字段。保护固定标题，分别核对图名、图号及日期。竖框改横框时保留正文比例并检查是否有足够空间。封面、目录、图签及台账的关联字段同步核对。
3. 将变更资料与现有主图和后期出图对照。记录适用范围及修改位置。整张替代前检查内容覆盖，局部变更写入对应主图，并核对关联页。确认替代后，将旧图纳入历史档案并从正式索引移除。依据不足时记录缺项，保留可核对的图号和位置。
4. 说明页按对应图签的实际字体统一正文、字高、栏宽和标题层级。先定位表格、工程符号、示意图和签名等保护对象。旧文字若已转换成轮廓，先逐行核对文字、单位、公式和数字，再替换可见字形。保留原图复杂表格和专业符号。采用竣工图叙述口径，图纸参数及试验要求不可改写为已测得的结果或已通过的验收。
5. 后台 AutoCAD 按张串行运行。每张使用独立可写副本和日志。运行器限制进程寿命，超时仅终止该次启动的进程组。脚本退出后，核对实际保存、回读 DWG，并在 CAD 检查对应页、字体、边界和外参。遇只读、退出提示或超时，检查日志及实际文件。复杂图页仍需人工核对。
6. 发布前保存可恢复版本。将验收通过的图纸和台账同步更新，核对相对路径、页次及 SHA-256。打包时检查外参和字体是否齐备，依授权分发资源，记录本轮成果、例外与可继续处理的位置。

## 原生后台运行

```sh
python3 scripts/run_core_console.py --timeout 120 --log work/job.log \
  work/drawing-copy.dwg work/edit.scr
```

默认路径对应 macOS AutoCAD 2027。可用 `--console` 指定其他兼容的 Core Console 路径。日志使用新文件，避免覆盖历史输出。返回码 124 表示超时，130 表示中断。退出成功只表示后台程序已结束，仍需核对保存结果。
